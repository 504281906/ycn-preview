# 数据平台 - 功能预览

数据标注与任务管理平台前端预览系统，涵盖数据资源管理、标注工具、任务包、专题视图等模块。

**在线访问：** https://504281906.github.io/ycn-preview/

---

## 项目概述

本项目为数据标注与管理平台的前端演示系统，支持图片分类、实体识别、目标检测、视频分割、音频分类等多种标注类型，提供完整的数据集管理、任务包管理、专题视图与系统设置等功能预览。

## 技术栈

- 纯前端 HTML + CSS + JavaScript（无需构建）
- 字体：PingFang SC / Microsoft YaHei / -apple-system
- 部署：GitHub Pages
- 设计风格：Ant Design -inspired（深色侧边栏 + 浅色内容区）
